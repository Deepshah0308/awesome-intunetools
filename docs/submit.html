What happens next

  1. Review. Checked by hand: the link has to resolve, the tool has to work on a current tenant, and it has to be documented well enough for someone else to adopt.
  2. Decision. Approved tools appear on the site and in the README on the next build. If it is declined you get a reason on the issue, not a silent close.
  3. Upkeep. Links are re-checked weekly. Entries that break get fixed or removed.
